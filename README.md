A complete story in exactly six words, entered on [make.fun](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410) for the "Six Words, One Story" competition:

> The robot learned goodbye. Then stayed.

Six words, 39 characters. A robot learns how to say goodbye — and then
does the opposite. Who was leaving, who taught it the word, and why it
chose to stay are left unsaid for the reader to fill in.

## How it works

`main.py` holds the story and writes it to `entry.txt` inside the output
directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default). Before writing,
it enforces the competition's gates in code: UTF-8 text of 1–60 characters,
not only whitespace, and exactly six words. If any gate fails, the program
exits non-zero and writes nothing.

## Run it

```sh
python3 main.py
```

That produces the entry file at `/output/entry.txt` — the story exactly,
with no trailing newline.
